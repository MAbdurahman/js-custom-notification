# js-custom-notification

<p>js-custom-notification is a toast notification written with HTML5, CSS3, and JavaScript. It is designed to closely imitate npm react-toastify.</p>

## Features
- [x] Customizable
- [x] Lightweight
- [x] Responsive
- [x] HTML5
- [x] CSS3
- [x] JavaScript
- [x] Normalize.css
- [x] Google Fonts
- [x] Font Awesome Icons
- [x] Mobile Friendly
